Save a copy to Google Drive

  1. Click Export all data (and/or Download database backup) on the left.
  2. Open drive.google.com → New → File upload → pick the downloaded file.

On the shop PC you can also install Google Drive for desktop and set the backup folder below to a folder inside it: every automatic backup then goes to Drive by itself.
